SimpleTodo

SimpleTodo est une application Android simple et intuitive de gestion de tâches, développée en Kotlin. Elle permet à l’utilisateur de créer, modifier et supprimer ses tâches quotidiennes pour mieux organiser son temps.
Fonctionnalités

    Création et édition de tâches avec date et description

    Suppression facile des tâches terminées

    Interface claire et épurée pour une expérience utilisateur fluide

    Stockage local des données pour un accès rapide et hors ligne

Technologies

    Langage : Kotlin

    Architecture : ...

    UI : Jetpack Compose ou XML (selon ce que vous avez utilisé)

    Stockage : Room ou autre base de données locale

    Outils : Android Studio, Gradle

Installation

    Cloner ce dépôt

    Ouvrir le projet dans Android Studio

    Construire et lancer l’application sur un émulateur ou un appareil Android
